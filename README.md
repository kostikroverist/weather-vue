# Погодник

## Що це

Тестове завдання Panda Team: додаток погоди на Vue 3, TypeScript, Vite, Pinia і Chart.js без CSS-фреймворків і UI-бібліотек. Дані з OpenWeather: поточна погода, прогноз на 5 днів з кроком 3 години, геокодер.

## Запуск

```sh
npm install
```

Створити `.env.local` у корені з ключем OpenWeather:

```
VITE_OWM_KEY=ваш_ключ
```

```sh
npm run dev
```

## Перевірки

```sh
npm run lint
npm run type-check
npm run test:unit
npx playwright install chromium
npm run test:e2e
```

- `lint`: oxlint і ESLint.
- `type-check`: vue-tsc.
- `test:unit`: Vitest і @vue/test-utils.
- `test:e2e`: Playwright у двох профілях, десктоп 1280×800 і мобільний 360×740. Запити до OpenWeather і сервісу IP підміняються фікстурами з `e2e/fixtures`, тож e2e не ходить у мережу і не потребує ключа.

## Деплой

Vercel. У налаштуваннях проєкту додати змінну середовища `VITE_OWM_KEY`. `vercel.json` переписує всі шляхи на `index.html`, щоб history mode роутера працював при прямому відкритті та перезавантаженні сторінок.

## Що реалізовано з ТЗ

1. Пошук міста з автокомплітом: debounce 300 мс, від 2 символів, скасування попереднього запиту, до 5 варіантів.
2. Запити через один інстанс axios з `appid`, `units` і `lang` в interceptor.
3. Картка поточного дня: температура, опис, «відчувається як», вологість, вітер, тиск, найближчий схід або захід.
4. Графік температури на Chart.js без vue-chartjs, зі стовпчиками опадів і смугою годин під ним.
5. До 5 блоків погоди, за замовчуванням один.
6. Видалення блоку через модалку підтвердження.
7. Вкладка «Вибране»: до 5 міст у localStorage, рамка на блоці з обраним містом, модалка при перевищенні ліміту.
8. Адаптивність: контейнер 1200px, мінімум 360px.
9. \* Перемикач «День / 5 днів»: 5 плиток з середньою, мінімумом і максимумом, графік середніх і сум опадів.
10. \* Місто користувача за IP при першому візиті.
11. \* Скелетони під час запитів погоди і пошуку.
12. \* Інтерфейс і відповіді API українською та англійською.
13. \*\*\* Тема «День / Ніч»: ручний вибір або «Авто».

## Понад ТЗ

14. \*\*
    - Блоки головної зберігаються в localStorage.
    - Підсумок опадів текстом на найближчі 24 години.
    - Погодинна деталізація дня в режимі «5 днів».
    - Модалка ліміту обраного із заміною міста.
    - Клавіатурна навігація автокомпліту.
    - Анімації інтерфейсу.
    - Автоматична тема за сходом і заходом сонця в місті першого блоку.

## Рішення й обмеження

- «Поточний день» на графіку — найближчі 24 години, 8 точок по 3 години. Безкоштовний тариф не дає погодинного прогнозу.
- Час у блоці — місцевий час міста за `timezone` з відповіді API.
- Режим «5 днів» — перші 5 дат у часі міста. Сьогодні може бути неповним днем.
- Автокомпліт геокодера OpenWeather шукає за повною назвою, тому підказки з'являються після введення назви. Результати, назва яких не починається з запиту, відсікаються.
- Після заходу сонця показується час сходу поточної доби: API не дає завтрашнього.
- Один зсув `timezone` на весь прогноз. Перехід на літній або зимовий час усередині 5 днів не враховується.
- Ключ API потрапляє в клієнтський бандл. Це обмеження архітектури без бекенду.
- Тека `docs/` з ТЗ і специфікацією у репозиторій не входить.
